# Mo 全球石油产业报告 / Mo Global Oil Industry Reports

Mo 刊物体系的公开出版物：事实与一般市场分析。Mo 自身经营内容见内部《Mo内参》，不在此公开。

Publications of the Mo journal system: facts and general market analysis only. Mo's own operational content is in the internal Mo Briefing and is not published here.

## 月报 Monthly — 《Mo全球石油产业月报》

每月最后一个日历日 08:00（北京时间）发布。上半部为上游产业全景，下半部为下游宏观分析。

Published on the last calendar day of each month, 08:00 Beijing time. First half: upstream panorama; second half: downstream macro analysis.

- `monthly/2026-10-30/` — 创刊号 Inaugural Issue（中英文 Word + PDF）

## 周报 Weekly — 《Mo石油产业周报》

每周日 20:00（北京时间）发布：产量与钻机变化、价格走势、OPEC 动态、本周大事、展望。

Published every Sunday, 20:00 Beijing time: production and rig changes, price trends, OPEC dynamics, the week's major events, outlook.

## 来源与口径 Sources

每期附录列明数据来源与口径。同一件事不同机构数字不同，是口径不同，不是谁算错了；查不到的数字直接写「无公开数据」，不估、不编。

Each issue's appendix lists data sources and definitions. Different institutions report different numbers for the same thing because of different definitions, not errors; unavailable data is written as "no public data", never estimated or invented.
